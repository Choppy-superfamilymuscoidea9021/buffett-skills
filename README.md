## 🧠 The Investment Philosophy

The software follows the principles of value investing. It ignores daily market noise. Instead, it looks for long-term indicators. 

Value investing focuses on the gap between the price of an asset and its actual worth. The software identifies this gap. It searches for companies with proven, consistent performance. It alerts you when the market price drops below the calculated value.

This framework applies to both traditional finance and newer technologies like blockchain. The software treats btc and ethereum as digital assets. It applies the same scrutiny to these as it does to traditional stocks. It avoids speculative ventures that lack underlying capital generation.
